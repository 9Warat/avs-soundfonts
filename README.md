# avs-soundfonts

Instrument sound banks for the "สร้างดนตรี" (music) page of AI Vocal Separator,
served through GitHub Pages so large downloads do not use the main site's bandwidth.

- `hq/` — MuseScore_General v0.2.0 (SoundFont 2, uncompressed, 215,614,036 bytes) split into
  9 MiB parts. `hq/manifest.json` lists the parts and the SHA-256 of the whole file.
  License: MIT, see `hq/LICENSE.md` (FluidR3 © Frank Wen 2000-02, FluidR3Mono © Michael Cowgill
  2014-17, adaptation by S. Christian Collins 2018-19, Temple Blocks © Ethan Winer 2002,
  Drumline Cymbals © Michael Schorsch 2016).

The same files are kept on the main site as a fallback.
